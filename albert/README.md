# Альберт — мультики для крипто-канала

Формат: диалог Альберта (крипто-наставник в оранжевом жилете) и Стаса (новичок), слова появляются по одному над говорящим, сверху — инфографика.

**Как сделать серию**
1. Сценарий — `albert/episodes/epNN.json`: реплики (`who`: `A` — Альберт, `S` — Стас), план (`shot`: `solo`, `duo`, `close`), поза (`pose`: idle, explain, chin, shrug, point, stop, head), инфографика (`info`: `icon`, `flow`, `big`, `label`).
2. **Actions → «Альберт — видео» → Run workflow** → имя эпизода.
3. Конвейер: Fish Audio озвучивает каждую реплику → Whisper размечает слова → Remotion рисует анимацию → FFmpeg собирает звук. Видео сохраняется в `albert/videos/` и приходит в Telegram.

**Настройки**
- Секрет `FISH_API_KEY` — ключ Fish Audio (fish.audio → API Keys).
- Голоса — `albert/voices.json`: `{"A": "<id голоса Альберта>", "S": "<id голоса Стаса>"}`. Id голоса — часть ссылки на голос на fish.audio (`fish.audio/m/<id>`). Если файла нет, бот сам выберет популярные русские мужские голоса.
- Уже озвученные реплики не переозвучиваются (экономия баланса). Переозвучить всё — галочка «Переозвучить» при запуске.
- Иконки инфографики: btc, cash, lock, doc, car, arrow, chartUp, chartDown, warn, tg, bank.

Remotion бесплатен для частных лиц и компаний до 3 человек; для больших команд нужна лицензия.
