# Бот персонажа «Виктор Платонов» — Instagram + Threads

Бот сам ведёт оба аккаунта: 70% — лайфстайл (мысли, фото «жизни мечты»), 30% — разборы матчей со ссылкой на Telegram.

| Время (МСК) | Где | Что |
|---|---|---|
| 09:10 | Threads | Мысль дня (бизнес, дисциплина, вопрос аудитории) |
| 12:40 | Threads | Разбор матча дня + ссылка на Telegram в первом комментарии |
| 16:10 | Threads | Фото дня с короткой подписью |
| 18:30 | Instagram | Фото дня с подписью, а 3 дня из 10 — фирменная карточка разбора матча |
| 20:10 | Threads | Раз в 3 дня — экспресс вечера со ссылкой на Telegram, в остальные дни — мысль |

Прогнозы берутся с сайта (`data/predictions.json`), лайфстайл-тексты — из `persona/content.json`. Ежедневная задача сама дописывает новые тексты, когда запас подходит к концу.

Фото: бот берёт их из бесплатного фотобанка **Pexels** (машины, яхты, виды, часы — без узнаваемых лиц) и обрезает под формат Instagram 4:5. Если хотите свои фото — загрузите их в папку `persona/inbox/` (на GitHub: **Add file → Upload files**). Свои фото бот всегда ставит первыми. Подпись можно положить рядом в файле с тем же именем: `yacht.jpg` + `yacht.txt`.

## 1. Аккаунты

1. Создайте Instagram `viktor.platonov` (или близкий свободный ник). Переключите на профессиональный: **Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт → Автор**.
2. Войдите в Threads через этот Instagram — аккаунт Threads создастся автоматически.
3. Шапка профиля:
   - Instagram: `Виктор Платонов · В.И.П.` / `IT-бизнес · инвестиции · путешествия` / `Разбираю матчи как бизнес-кейсы` / `18+ · разборы в Telegram 👇`
   - Threads: `IT-бизнес, инвестиции, путешествия. Разбираю матчи как бизнес-кейсы. 18+ · разборы в Telegram 👇`
   - В поле «Ссылки» обоих профилей — `https://t.me/+csmS0KuVLIowNTRi`. В Instagram ссылки в подписях не кликаются, поэтому посты отправляют людей «в шапку профиля».
4. Перед запуском бота выложите вручную 3–6 постов и поживите в аккаунте пару дней (лайки, подписки): новые аккаунты, которые сразу начинают постить через API, чаще ограничивают.

## 2. Приложение Meta (VPN)

Используйте то же приложение, что и для Threads (инструкция — `THREADS_SETUP.md`, шаги 1–2), но подключайте аккаунт Виктора.

Для Instagram в том же приложении:
1. **Варианты использования → Добавить → «Управление сообщениями и контентом в Instagram»** (Instagram API, вход через Instagram).
2. Разрешения: **instagram_business_basic** и **instagram_business_content_publish**.
3. **Роли приложения → Роли → Тестировщики Instagram → Добавить** — ник Виктора. Принять приглашение: в Instagram на сайте **Настройки → Приложения и сайты → Приглашения тестировщика**.
4. **Настройка API со входом через Instagram → Сгенерировать маркеры доступа → Добавить аккаунт** → войдите как Виктор → скопируйте токен (действует 60 дней).

## 3. Ключ Pexels (бесплатно, 2 минуты)

pexels.com → зарегистрируйтесь → **pexels.com/api** → **Your API Key** → скопируйте ключ.

## 4. Секреты GitHub

`metod-vipbet` → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Что это |
|---|---|
| `THREADS_ACCESS_TOKEN` | токен Threads аккаунта Виктора |
| `INSTAGRAM_ACCESS_TOKEN` | токен Instagram из шага 2.4 |
| `PEXELS_API_KEY` | ключ Pexels |
| `GH_PAT` | по желанию — для автопродления токенов (см. `THREADS_SETUP.md`, шаг 5) |

`THREADS_USER_ID` и `INSTAGRAM_USER_ID` указывать не нужно — бот узнает их по токену.

Токены — ключи от аккаунтов: никому их не пересылайте и не вставляйте в чаты.

## 5. Проверка

**Actions → Персонаж → Run workflow**: выберите слот (например, `th_photo`), оставьте галочку «Только проверка» → **Run**. В логе будет текст поста. Потом запустите без галочки — пост выйдет. Дальше всё работает по расписанию.

Старый бот «Threads» (100% прогнозов) теперь запускается только вручную, чтобы не ломать пропорцию 70/30.

## Правила, которые бот соблюдает

- Лайфстайл-посты — без ставок, букмекеров и ссылки на Telegram. Посты о спорте — без роскоши и денег.
- Ставки не подаются как способ заработка или путь к успеху (ФЗ «О рекламе», ст. 27). В каждом посте о спорте — 18+ и «это мнение, а не гарантия».
- Никаких «скринов выигрышей», сумм и промокодов. Ссылка — только на Telegram.
- Фото из Pexels разрешено использовать бесплатно, но без узнаваемых людей в роли «друзей» или «девушек» персонажа. Если будете выкладывать фото, сгенерированные нейросетью, ставьте при публикации метку «Создано с помощью ИИ» — этого требуют правила Meta.
- Не чаще 5 постов в день в Threads и 1 в Instagram — безопасный темп для нового аккаунта.

## Что ещё можно сделать руками (это даёт больше всего роста)

- Отвечать на комментарии в первый час после поста.
- Сторис в Instagram 3–5 раз в неделю (API сторис бот не публикует): кофе, дорога, спортзал, опрос «Кто сегодня победит?» со ссылкой-стикером на Telegram.
- Reels 2–3 раза в неделю: короткие видео-атмосферы (машина ночью, море, город) с текстом-мыслью.
