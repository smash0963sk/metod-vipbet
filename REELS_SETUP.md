# Бот рилсов — Instagram

Бот сам выкладывает рилсы Альберта и Алекса в Instagram по расписанию. Сценарий: `.github/workflows/reels.yml`, код: `scripts/reels_bot.py`.

| Аккаунт | Что публикует | Когда (МСК) |
|---|---|---|
| `albert` — Альберт · крипта | `albert/videos/r01…r14`, затем `ep01`, `ep02` | 19:07 |
| `alex` — Алекс · спорт | `albert/videos/s01…s10` | 20:07 |

Каждое видео выходит один раз и идёт строго по очереди. Новые ролики, которые соберёт сценарий «Альберт — видео», бот подхватит сам. Если очередь закончится, бот напишет в Telegram.

## Подключение (один раз на каждый аккаунт)
1. Переведите Instagram в профессиональный режим: **Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный → Автор**. В «Ссылки» профиля добавьте Telegram.
2. На developers.facebook.com откройте приложение. Если его нет, создайте. Затем: **Варианты использования → «Управление сообщениями и контентом в Instagram»**, разрешения `instagram_business_basic` и `instagram_business_content_publish`.
3. **Роли приложения → Тестировщики Instagram → Добавить** — ник аккаунта. Примите приглашение на instagram.com: **Настройки → Приложения и сайты → Приглашения тестировщика**.
4. **Настройка API со входом через Instagram → Сгенерировать маркеры доступа → Добавить аккаунт**. Войдите в этот Instagram и скопируйте токен.
5. GitHub → **Settings → Secrets and variables → Actions → New repository secret**:
   - `IG_ALBERT_TOKEN` — токен аккаунта Альберта;
   - `IG_ALEX_TOKEN` — токен аккаунта Алекса.

   Токен в чат не присылайте, только в секреты.
6. Проверка: **Actions → «Рилсы — Instagram» → Run workflow → mode: status**. Напротив аккаунта должно быть написано «API».

Токены живут 60 дней. Сценарий «Продление токенов» обновляет их 1 и 20 числа (нужен секрет `GH_PAT`).

## Пока токенов нет
В момент публикации бот присылает вам в личный Telegram видео и готовую подпись. Нажмите на подпись, она скопируется. Выложите ролик в Instagram — это займёт около 30 секунд.

## Настройки — `reels/accounts.json`
- `times_msk` — время публикации. Можно несколько: `["13:07", "19:07"]`. Для нового аккаунта безопасный темп — 1–2 рилса в день.
- `videos` — какие файлы публикует аккаунт и в каком порядке.
- `hashtags`, `footer` — что добавляется в конец каждой подписи.

Подписи к роликам лежат в `reels/captions.json`. Если подписи нет, бот соберёт её из сценария сам.

Выложить ролик вне очереди: **Run workflow → mode: now → account → video** (например `r05`).
