# Как подключить бота Threads

Бот каждый день публикует в ваш аккаунт Threads три поста с сайта:

| Время (МСК) | Пост |
|---|---|
| 09:40 | Итоги вчерашнего дня (если есть сыгранные прогнозы) и «Ставка дня» |
| 13:40 | «Верняк дня» |
| 17:40 | «Экспресс дня» |

К каждому посту прикрепляется ссылка на страницу прогноза на сайте. Повторов не бывает: бот запоминает опубликованное в `data/threads_state.json`.

Пока секреты не добавлены, бот работает в режиме проверки: готовит тексты, но ничего не публикует.

## 1. Создайте приложение Meta (один раз, ~10 минут)

Сайты Meta из России открываются только через VPN.

1. Откройте **developers.facebook.com** и войдите (подойдёт аккаунт Facebook или Instagram, связанный с Threads).
2. **Мои приложения → Создать приложение**. В сценариях использования выберите **«Доступ к API Threads»** (Access the Threads API). Название — любое, например `VIPBET bot`.
3. В приложении: **Варианты использования → API Threads → Настроить**. Добавьте разрешения **threads_basic** и **threads_content_publish**.
4. **Роли приложения → Роли → Тестировщики Threads → Добавить** — впишите имя своего аккаунта Threads.
5. В Threads (в приложении или на threads.net): **Настройки → Аккаунт → Разрешения веб-сайтов → Приглашения** — примите приглашение.

## 2. Получите токен и id аккаунта

1. В приложении Meta: **Варианты использования → API Threads → Настройки → Генератор токенов пользователей** → **Сгенерировать токен** для вашего аккаунта. Скопируйте токен.
2. Если сгенерированный токен короткий (действует 1 час), обменяйте его на долгий (60 дней). Откройте в браузере, подставив свои значения (секрет приложения — в **Настройки приложения → Основное**):
   `https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=СЕКРЕТ_ПРИЛОЖЕНИЯ&access_token=КОРОТКИЙ_ТОКЕН`
   В ответе будет новый `access_token` — он и нужен.
3. Узнайте id аккаунта — откройте:
   `https://graph.threads.net/v1.0/me?fields=id,username&access_token=ВАШ_ТОКЕН`
   Скопируйте число из поля `id`.

## 3. Добавьте секреты в GitHub

Репозиторий `metod-vipbet` → **Settings → Secrets and variables → Actions → New repository secret**:

- `THREADS_USER_ID` — число из шага 2.3;
- `THREADS_ACCESS_TOKEN` — токен из шага 2.1 или 2.2.

Токен — это ключ от вашего аккаунта: не пересылайте его никому и не вставляйте в чаты.

## 4. Проверьте

**Actions → Threads → Run workflow**: выберите слот `morning`, оставьте галочку «Только проверка» и нажмите **Run**. В результатах запуска будут тексты постов. Если всё нравится — запустите ещё раз без галочки: пост появится в Threads. Дальше бот работает сам по расписанию.

## 5. Автопродление токена (по желанию)

Токен Threads действует 60 дней. Сценарий «Threads — продление токена» продлевает его 1 и 20 числа каждого месяца, но для сохранения нового токена ему нужен ключ GitHub:

1. **github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Repository access: **Only select repositories** → `metod-vipbet`. Permissions → Repository → **Secrets: Read and write**. Срок — максимальный.
3. Сохраните его как секрет репозитория `GH_PAT`.

Без `GH_PAT` раз в 60 дней нужно вручную получить новый токен (шаг 2) и заменить секрет `THREADS_ACCESS_TOKEN`.

## Настройки

- По умолчанию в постах **нет промокода и ссылки на букмекера** — только прогноз и ссылка на ваш сайт. Правила Meta ограничивают продвижение азартных игр, и посты с промокодами могут скрывать или удалять. Если всё же хотите добавить промокод, поставьте `"threads_with_promo": true` в `scripts/site_config.json`.
- Время постов меняется в `.github/workflows/threads.yml` (строки `cron`, время в UTC = МСК − 3 часа).
